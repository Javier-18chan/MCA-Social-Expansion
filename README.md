# MCA Social Expansion

MCA Social Expansion amplía MCA Reborn con interacciones sociales, relaciones, reputación, regalos y distintas interfaces de comunicación.

## Compatibilidad

- Minecraft 1.20.1
- Forge 47 o posterior
- Java 17
- MCA Reborn 7.7.1-alpha.1 o posterior

Integraciones opcionales:

- MCA Quests 1.1.0 o posterior
- MCA Conversations 1.0.0 o posterior
- Townstead 0.7.6 o posterior

## Compilación

Coloca MCA Reborn y Architectury para Forge en `libs/` con los nombres esperados por `build.gradle`. Después ejecuta:

```powershell
.\gradlew.bat build
```

El JAR compilado se genera en `build/libs/`.

## Idiomas

El mod incluye traducciones para inglés de Estados Unidos, español de España, español de México, español de Estados Unidos y portugués de Brasil.
